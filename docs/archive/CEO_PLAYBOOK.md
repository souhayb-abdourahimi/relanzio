# CEO Operating System

## North-star de validation
Nombre de comptes qui ajoutent de nouveaux devis plusieurs semaines de suite. Le MRR vient ensuite.

## Funnel hebdomadaire
Visiteurs → inscriptions → activés (1er devis) → payants → retenus.
Acquisition : prospects qualifiés → emails → réponses → réunions → pilotes → clients.

## Revue du lundi — 30 minutes
1. Activation <50 % avec 5+ signups : corriger onboarding avant acquisition.
2. Reply rate <10 % après 20 envois : revoir ICP/message avant volume.
3. Utilisateurs activés mais non payants : 5 interviews avant baisse de prix.
4. Fonction demandée 3+ fois : évaluer impact activation/rétention/revenu.
5. Churn : contacter humainement chaque départ tant que <100 clients.

## Règle de roadmap
Construire seulement si au moins un critère est vrai :
- 3+ demandes indépendantes ;
- bloque activation/paiement ;
- réduit un coût/support mesurable ;
- améliore une métrique stratégique mesurable.

## Seuils
Pilotes : 5 actifs.
Premiers payants : 2 après usage.
Preuve initiale : 10 payants + usage récurrent.
Objectif 500 MRR : ~18 comptes à 29 €.
Publicité payante : après canal organique et rétention initiale.
