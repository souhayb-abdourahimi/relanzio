## Compétences à apprendre dans cet ordre

Vente découverte B2B → copywriting simple → déploiement Node/Supabase → délivrabilité email → métriques SaaS → RGPD opérationnel → SEO. Ne pas commencer par la publicité payante.

## Budget de validation

Domaine : ~10–20 €/an selon registrar/extension.
Hébergement MVP : viser ~5–10 €/mois.
Base : commencer gratuit si adapté.
Email : commencer gratuit/faible volume.
IA : optionnelle ; définir un plafond de dépense.
Publicité : 0 € pendant la validation.
