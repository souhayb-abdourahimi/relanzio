# Système d'acquisition Relanzio

## ICP de départ
Agences web/marketing/design et petites entreprises de service : 1–10 personnes, 5+ devis/propositions par mois, panier moyen > 500 €, décideur accessible, outils numériques déjà utilisés.

## Pipeline
Source professionnelle → import documenté → score → revue humaine → message → cooldown 7 jours → réponse → analyse IA → insight → rendez-vous/pilote.

## Règles
- pas de scraping caché dans Relanzio ;
- source et URL obligatoires pour un email nominatif ;
- adresse générique acceptée si pertinente ;
- score <55 : aucun envoi ;
- plafond par défaut : 20 emails/jour ;
- une sollicitation max / 7 jours ;
- suppression vérifiée avant chaque envoi ;
- identité de Relanzio + moyen d'opposition dans chaque message ;
- ouverture email stockée si le fournisseur la fournit, mais jamais utilisée comme KPI d'intention principal.

## Sources de prospects recommandées
Répertoires professionnels publics, sites officiels d'entreprises, partenaires, événements B2B, recommandations, exports de CRM dont l'usage est licite. Ne pas acheter une base opaque sans connaître la provenance et l'information des personnes.

## Message découverte
Objet : Question sur le suivi de vos devis

Bonjour [Prénom],

Je travaille sur Relanzio, un outil pour les petites entreprises qui envoient régulièrement des devis et veulent mieux suivre ceux qui restent sans réponse, sans changer leur logiciel actuel.

Avant de développer davantage, je cherche à comprendre le workflow réel. Aujourd'hui, comment suivez-vous les devis auxquels un client ne répond pas ?

— Relanzio

## Réponse intéressée
Merci. Le plus utile serait de vous montrer le workflow sur un exemple réel pendant 10 minutes. Je cherche surtout à vérifier si le produit correspond à votre façon de travailler. Quel créneau vous conviendrait ?

## Pas maintenant
Merci pour votre retour. Je ferme la boucle pour l'instant. Si vous m'indiquez une période pertinente, je peux noter un seul rappel ; sinon je ne vous relance pas.

## Prix
La formule visée est 29 €/mois. Avant de vous demander de payer, je préfère vérifier avec vous qu'un vrai devis est suivi de bout en bout et que le workflow est utile chaque semaine.

## Fonction manquante
Merci. Aujourd'hui cette fonction n'existe pas. Je note la demande et je ne vous promets pas de date tant que plusieurs utilisateurs ne confirment pas le même besoin.
